# MVP — Minimum Bar

Full grading detail (what separates each level) lives in `rubric.md`. This is
the bar:

- [ ] **Column data types.** At least 5 of 6 columns correctly typed, each
  with a real reason from actual column-preview output.
- [ ] **List vs. table** explained in your own words.
- [ ] **Structured vs. unstructured** stated, with a reason.
- [ ] **Two collection-process concerns** identified.
- [ ] **One data-quality question** — the most checkable of those two, turned
  into a specific, answerable question for the source.
- [ ] **A separate curiosity question** — genuinely different from the
  data-quality one.
- [ ] **AI-literacy reflection** — 2 concrete risks + one specific personal
  rule for double-checking AI output.
- [ ] **Terminal log** — real commands throughout, including one real error
  and how you diagnosed it.
- [ ] **GitHub repo** — public, contains `field_notes.md` and `README.md`.
  No Python file expected.
- [ ] **Commit history** — at least 2 commits, each with a real, descriptive
  message.

See `CHECKLIST_TIMELINE.md` for the day-by-day sequence this bar is built in.
